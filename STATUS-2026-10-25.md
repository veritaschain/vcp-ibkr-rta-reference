# Status correction — 25 October 2026

This file corrects the current-tense status of this repository. It is a separate file because `README.md`, `verify.py`, `CHANGELOG.md`, `LICENSE` and the other pack files are listed in `hash_manifest.json`; editing them would break the manifest. Whether to annotate the README and regenerate the manifest is an owner decision. Statements in the hash-covered files predate this correction.

- This is a first-party evidence pack by VeritasChain Co., Ltd., which operates the VeritasChain Standards Organization (VSO). It targets VCP v1.1 (Gold tier). VCP v1.1 has no tagged release and is superseded by VCP v1.2 (Released, tag `v1.2.0`).
- Conformance to any VCP tier, or to VAP, has not been independently established. "Full VCP v1.1 specification compliance", "Gold Tier Institutional Compliance" and the `FULLY COMPLIANT` / "fully compliant" lines printed by `verify.py` and quoted in the README are not results. There are zero external implementations of VAP or any of its profiles, including VCP.
- Not certified. VSO does not issue certificates. The certification scheme requires a Conformity Assessment Body (CAB) independent of the scheme owner; the only registered CAB, VeritasChain Co., Ltd., is not independent (VAP v1.2 ERRATA E-2026-10-21). The README line "For official VC-Certified status, contact: certification@veritaschain.org" is superseded by this rule. Conformance is not compliance (VAP v1.2 §1.6). The README's "Cryptographic Guarantee" column should read "Verification mechanism".

## Known limitations of this pack

- **Demo keys.** `CHANGELOG.md` states "Ed25519 signature algorithm (demo keys)". (`keys/key_manifest.json` describes a production HSM key; the two statements conflict.)
- **No signatures.** The events carry `SignAlgo` in the header but no signature values, and `verify.py` does not verify signatures.
- **Placeholder account.** The account identifier is `U12345678` throughout. The `PRODUCTION`, `LIVE_TRADING` and `synthetic_data: false` labels in `datasets/metadata.json` are not substantiated by anything in the pack.
- **No external anchor proof.** `anchors.json` names `TIMESTAMPING_AUTHORITY` but contains no TSA token and no signature. `verify.py` checks the anchor only by comparing its `MerkleRoot` string with the computed root. The pack therefore does not show external anchoring (VAP v1.2 INT-006).
- **Gold anchor cadence not met.** Gold requires anchoring every hour (VAP v1.2 §5.1.3; VCP v1.2 §2.1). The pack declares `AnchorFrequency: "DAILY"` and has one anchor.
- **Dates may be mis-stated (2025 vs 2026).** The pack and `CHANGELOG.md` are dated 2025-01-06 but cite VCP v1.1, which was published on 2025-12-30; `events.json` and `hash_manifest.json` were generated on 2026-01-06 (the date the files were committed). The dates are not corrected because the files are hash-covered.
